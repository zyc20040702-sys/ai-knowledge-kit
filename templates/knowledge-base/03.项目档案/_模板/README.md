# 项目名（请替换）

> 一句话说明项目是什么、当前状态、主责角色。  
> 整理日期：YYYY-MM-DD

## 本目录结构

| 路径 | 放什么 |
| --- | --- |
| `01-输入/` | 需求、素材、外部约束（无密钥） |
| `02-决策/` | 拍板与取舍 |
| `03-代码与配置说明/` | 架构、路径、非机密配置 |
| `04-交付/` | 发布说明、验收与交付清单 |
| `05-复盘/` | 结果与改进 |
| `source/` | 完整可打开的无密钥源码树 |
| `packages/` | 灾难恢复 zip：`<项目>-source-<版本>-<YYYYMMDD>.zip` |
| `源码包说明.md` | （建议）版本、打包日、包含/排除、如何恢复 |

## 交档硬门槛

**无源码包不算完成交档。** 说明文档不能替代 `packages/*.zip` 与/或 `source/`。

## 勿入库

密钥、`.env`、私钥、Cookie、真实用户隐私数据、依赖与构建缓存、超大无关媒体（单文件 >50MB 须另说）。
