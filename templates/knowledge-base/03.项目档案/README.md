# 03.项目档案

保存一次真实项目的全过程：输入、目标、关键决策、执行记录、交付物、**可复原源码包**、结果和复盘。

## 交件规则（强制）

1. **一个项目一个文件夹**：优先 `项目名/`；需要区分批次时用 `YYYY-MM-DD-项目名/`。
2. **可复原源码包（强制）**：每个进行中 / 已交付项目**必须**有无密钥可复原源码，至少二选一，**建议两者都有**：
   1. `packages/<项目>-source-<版本>-<YYYYMMDD>.zip`（灾难恢复主用；解压即项目根）
   2. `source/` 下完整可打开的源码树（便于 AI / 人直接读）
   - **无源码包不算完成交档**。说明文档不能替代源码包。
3. **建议子目录**（可按项目裁剪，模板见 `_模板/`）：
   - `01-输入/` · `02-决策/` · `03-代码与配置说明/` · `04-交付/` · `05-复盘/`
   - `source/` · `packages/`
4. **严禁放入**：密钥、`.env`、私钥、Cookie、真实用户隐私数据、`node_modules`、构建缓存；单文件 >50MB 的媒体须另说明。
5. 长期通用方法升级到 `skills/` 或 `system/PROCEDURES.md`；可复用资料回到 `01.资料库/`。

## 模板

新建项目可复制 `_模板/` 后改名填写。交档前确认已有源码包。

> **真实项目档案只放私有仓。** 本开源 kit 不收录任何真实项目源码或业务数据。
