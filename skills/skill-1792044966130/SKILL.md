# 学术汇报内容稿

## 目标
把长文述评压成「可上台讲」的分页内容：每页标题、3–6 条短句、可选讲者备注；方便下一步用任意幻灯片流程排版。

## 步骤
1. **定主线**：默认「问题缘起 → 文献/分析地图 → 关键共识或发现 → 缺口或争议 → 结论/切入点」；按用户时长压缩页数（常见 10–16 页）。
2. **分页写内容**：每页只保留口头能讲完的信息；少写完整文献名，关键理论用「一笔带过」即可。
3. **做一张关系图页**：用模块/变量之间的箭头关系代替长列表。
4. **缺口页条目化**：每条一行，末尾指向切入点。
5. **备注栏**：为关键页写 1–2 句讲者提示（过渡语、可省略项）。
6. **交接**：标明「内容口径以某 Word 为准」；若用户要改模板配色，留给幻灯片制作步骤，本技能不锁定视觉模板。

## 约束
- 不引入正文没有的新结论。
- 不做最终美化排版（那是幻灯片制作步骤）。
