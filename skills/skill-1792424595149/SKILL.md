# 小程序雷达

线上选型与风险评估工具，把微信小程序生态资源做成可筛选雷达。

- 主站：https://miniapp.jjc.fun
- 备用：https://wechat-miniapp-radar.vercel.app
- 仓库（只读参考，默认不装本机）：https://github.com/justjavac/wechat-miniapp-radar
- 许可：GPL-3.0 → **只用官方线上站**；自建托管或二次分发须标「先过法务」，且须用户明确同意后再做。

## 何时使用

- 小程序技术选型（Taro / uni-app / 原生 / 组件库 / 云开发）
- 对比方案、看维护状态与风险
- 粘贴项目配置做迁移诊断
- 看生态周报或近期风险信号
- 用户说「小程序雷达」「开雷达」「Doctor」「Compare」

## 做法

1. **默认只开线上站**，不 clone、不 npm 落地、不自建部署。
2. 按需求带用户（或自行浏览器）进对应入口：
   - Radar `/radar`：按推荐/风险/类型筛选资源
   - Compare `/compare`：对比核心框架方案
   - Advisor `/advisor`：选型问答（结论 + 适用条件 + 证据）
   - Doctor `/doctor`：粘贴小程序项目配置，识别过时栈与迁移风险
   - Weekly `/weekly`：周报与风险信号
3. 把结论用简体中文短述：推荐什么、风险、是否值得试；已有同类能力则说明「可不换」。
4. 需要本机自托管时：先提醒 GPL「先过法务」，等用户明确同意再动手。

## 不做

- 不擅自安装仓库到本机或云主机
- 不把雷达当虚拟支付 / 成片工具替代
