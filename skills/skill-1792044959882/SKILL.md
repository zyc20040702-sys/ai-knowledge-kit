# 文献述评成稿

## 目标
在知识骨架齐备的前提下，产出可提交的文献述评正文（Word），并附上台演讲页级大纲；不替代用户指定的幻灯片技能流程。

## 步骤
1. **读入输入**：确认整理稿中的共识、缺口、切入点与分模块论据索引齐全；缺块先补齐再写。
2. **统一口径**：同一指标多来源时，择一主口径或注明「不同来源口径」；年份、门店数、份额等关键数字写前核对。
3. **撰写结构（总—分—合）**：
   - 开篇总述：四条（或多条）文献线索与整合目标。
   - 分块述评：每块按「概念/进展 → 关键发现 → 小结局限」展开，少堆文献名、多写论证关系。
   - 综合述评：跨模块共识 + 条目化研究缺口。
   - 收束：研究切入点与预期贡献，与研究背景/意义呼应。
4. **篇幅与文风**：默认学术书面语、简体中文；篇幅按课程要求（常见 2500–4000 字可调）；段内论证完整，避免提纲体充数。
5. **参考文献**：按 GB/T 7714 整理文中已引用文献；材料信息不全处标注待补，不虚构条目。
6. **演讲配套**：给出 10–16 页页级大纲，主线固定为「问题缘起 → 文献地图 → 共识 → 缺口 → 切入点」；提醒台上少念文献名。
7. **交付**：输出 Word 正文；若用户同时要 PPT，再按用户指定的幻灯片流程制作，内容口径与 Word 一致。

## 约束
- 不编造文献与数据。
- 不把背景段原样粘贴进述评；要更系统、更批判。
- 保持通用，不绑定特定品牌或固定页模板。
