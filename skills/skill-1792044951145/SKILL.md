# 文献知识整理

## 目标
把多模块、多文件的文献材料整理成可直接用于「文献述评 / 开题 / 汇报」的知识骨架，而不是直接代写终稿。

## 步骤
1. **清点材料**：列出每份文件对应的主题模块；用可用工具抽取全文（docx / PDF 文本层）；扫描件或版式噪声大时注明需回看原件核对。
2. **建逻辑链条**：用一两句话说明各模块如何咬合（例如：理论前因 → 策略工具 → 情境约束 → 对象证据）。
3. **提炼共识**：按模块各写 2–4 条可引用的共识，每条带关键作者/年份或报告来源；避免堆砌摘要。
4. **提炼缺口**：跨模块归纳 3–6 条研究缺口（场景、情境、整合、测量/文化、对象等），每条说明「已有什么 / 还缺什么」。
5. **明确切入点**：用一段话写出研究情境、对象、要回答的问题，以及理论/情境/实践三类预期贡献。
6. **给出写作与演讲骨架**：
   - Word：总—分—合章节提纲（开篇总述 → 分块述评 → 综合缺口 → 切入点）。
   - PPT：页级大纲，突出「共识 → 缺口 → 切入点」，建议页数与可压缩项。
7. **质量备忘**：标注口径冲突（同一指标多来源）、引用格式注意点、哪些数据必须回原件核对。
8. **交付**：输出一份结构化整理稿（优先 Word），文末写清交接说明：本稿是知识骨架，正式述评/PPT 由后续成稿步骤完成。

## 约束
- 不编造未在材料中出现的文献、数据或结论。
- 不做冗长复述；优先批判性整合。
- 技能保持通用：不绑定具体课程名、品牌名或固定小组分工。
