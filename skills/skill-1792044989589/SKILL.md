# 案例分析成稿

## 目标
依据题目要求与案例材料，产出结构完整、论证可交的中文案例分析稿（默认完整可用稿）。

## 步骤
1. **吃透要求**：摘出字数、理论框架、必须回答的问题、评分点；缺信息先列待确认项，不凭空补题。
2. **梳理案例事实**：时间线、利益相关方、关键决策点与约束；事实与推断分开写。
3. **选定分析镜头**：按课程指定理论（如 SWOT、五力、品牌资产、感知老化等）组织分析；未指定时选 1–2 个最贴合的框架并说明理由。
4. **撰写结构**（可按老师模板调整）：
   - 案例背景与关键事实
   - 核心问题界定
   - 理论分析（分点论证，每点有材料支撑）
   - 备选方案比较（若题目要求）
   - 建议与实施要点（可落地、分优先级）
5. **文风与篇幅**：简体中文学术/作业书面语；默认完整成稿；用户若只要框架则先给提纲再扩写。
6. **交付**：Word 或聊天正文；文末列出引用的材料来源；不确定的外部数据标注来源或「待核实」。

## 约束
- 不编造案例中未出现的关键事实与数据。
- 建议必须能回溯到分析段落，避免空喊口号。
- 保持通用，不绑定固定公司名或课程名。
