# 课程作业成稿

## 目标
把题目与材料落到可提交的完整作业正文，优先对齐评分点，而不是只给空泛提纲。

## 步骤
1. **拆题**：题干、必答小问、格式（字数/标题/引用）、截止与提交形式；列表核对「每问是否已答」。
2. **对齐材料**：用户提供的讲义、笔记、文献、数据优先；不足处标明需补充，不虚构引用。
3. **定结构**：按小问分节；每节先给论点句，再展开论据与小结。
4. **写作**：简体中文；默认完整可用稿；专有名词首次出现可括注；公式/图表用文字说明或占位，勿假称已画图。
5. **自检**：对照评分点打勾；统一术语与口径；参考文献按课程要求（常见 GB/T 7714）。
6. **交付**：Word 优先；若还需 PPT/汇报，另走对应技能，口径与正文一致。

## 约束
- 不编造文献、数据、访谈。
- 不替用户做学术不端（如整段抄袭）；基于给定材料改写与综合。
- 保持通用，不绑定固定学校或课程代码。
