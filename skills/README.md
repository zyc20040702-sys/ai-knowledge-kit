# skills

可重复执行的工作流。每条技能做什么、适用什么场景、输入输出大概是什么，见 [CATALOG.md](CATALOG.md)；仓库首页有同一份展示。

本目录有两类内容：

1. **带脚本与参考的完整副本：** `shengjiang-knowledge/`（初始化、资料扫描、健康检查，以及企业 / 自媒体模式说明）。按 `SKILL.md` 在本目录执行。
2. **手续副本：** 其余文件夹以 `SKILL.md` 为主。`shengjiang-viral-breakdown/` 另有来源对照和评测记录。正文若指向采集脚本、成片程序、界面检测器或小程序兄弟技能，那些文件需按该技能说明另行准备。

全量分岗对照请在你的**私有知识库**维护。本开源包只提供可复用手续。

贡献新 Skill 时：在本目录新增 `skills/<id>/SKILL.md`（或完整包），并同步更新 [CATALOG.md](CATALOG.md) 与仓库首页的「已有能力一览」。
