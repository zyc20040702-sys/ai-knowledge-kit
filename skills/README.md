# skills

可重复执行的工作流。本目录有两类内容：

1. **核心完整副本**（含脚本/参考）：生姜三套，可直接按 `SKILL.md` 执行。
2. **轻量手续副本**：其余 Skill 仅含 `SKILL.md`，供任意 AI 在本仓内阅读手续；可安装的完整包可能在各 AI 自己的 skill 加载目录，视客户端而定。

全量目录请在你的**私有知识库**维护一份 Skill 清单与分岗对照；本开源包只提供可复用 Skill 手续。

贡献新 Skill 时：在本目录新增 `skills/<id>/SKILL.md`（或完整包），并在你的私有知识库同步更新 Skill 清单与分岗对照。
